# Contributing

The easiest way to help is to lend a machine: point your coding agent (Claude
Code, Codex, or similar) at [AGENTS.md](AGENTS.md) and let it walk you through
joining. Read [docs/SAFETY.md](docs/SAFETY.md) first; it says exactly what the
client may and may not do on your machine.

## What we accept

- Fixes and improvements to the client (`client/`), coordinator
  (`coordinator/`) and site (`site/`) that keep every rule in
  [docs/SAFETY.md](docs/SAFETY.md).
- Lean work for Track M (formalizing Masullo's paper) and checked English
  module cards for Track A (the map of Alpöge's proof), following
  [docs/PLAN.md](docs/PLAN.md). Locked statement files are not edited.
- Bug reports and clear questions as GitHub issues.

We don't accept changes that make the client download or run code on its own,
send credentials or personal data anywhere, or weaken the sandbox. Security
issues go through [SECURITY.md](SECURITY.md), not public issues.

## Credit

swarm handle) and it will appear wherever the result is used.
